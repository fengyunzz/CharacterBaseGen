# 表情 tag 到中文提示词参考

从这里挑选表情，再转写成自然中文。表情变化要有强度差异，不要用同义词凑数。

| tag | 中文转写 |
|---|---|
| neutral | 平静表情 |
| smile | 微笑 |
| happy | 开心 |
| cheerful | 开朗愉快 |
| serious | 认真 |
| calm | 冷静 |
| shy | 害羞 |
| surprised | 惊讶 |
| curious | 好奇 |
| confident | 自信 |
| determined | 坚定 |
| angry | 生气 |
| sad | 难过 |
| worried | 担心 |
| sleepy | 困倦 |
| playful | 调皮 |

## 选择规则

- 默认表情以清晰、可训练为主。
- 夸张表情数量不要过多，避免破坏角色身份稳定。
- 同一视角下可以换表情，但应避免动作和表情都几乎不变。
