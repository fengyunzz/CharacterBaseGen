# 动作 tag 到中文提示词参考

从这里挑选动作骨架，再转写成中文自然语言。不要把骨架相同的动作当成不同条目。

|---|---|
| standing | 自然站立 |
| walking | 向前行走 |
| running | 奔跑 |
| sitting | 坐姿 |
| kneeling | 单膝跪姿 |
| jumping | 轻微跳起 |
| turning around | 回头转身 |
| looking back | 回头看向镜头 |
| arms crossed | 双臂交叉 |
| hand on hip | 单手叉腰 |
| waving | 抬手挥手 |

| lying down | 躺姿 |
| stretching | 伸展身体 |

## 选择规则

- 动作池应覆盖静态、轻动态、强动态。
- 训练底图优先选轮廓清楚、遮挡少的动作。
- 同一批里不要连续使用动作骨架相同的站姿。
- 手、尾巴、饰品的小变化不能单独算新动作。
