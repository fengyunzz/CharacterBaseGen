# 标签清洗方法论

`/lora-label` 的目标是清洗外部打标器生成的 `.txt` 标签，而不是重新理解图片。

## 最小变量原则

- 能不改就不改。
- 只删除明显错误、重复、冲突或过度冗余的标签。
- 只补充用户已确认的 trigger、类名和稳定身份字段。
- 不根据 `prompts.md` 推断图片内容。
- 不调用视觉工具读取图片。

## 清洗顺序

1. 统一分隔符。
2. 前置 trigger。
3. 删除重复标签。
4. 删除明显冲突标签。
5. 统一视角、景别、动作、表情、背景字段。
6. 标记需要用户回看图片确认的冲突。

## 常见问题

- 如果同一文件出现互相冲突的人数标签，删除明显错误的人数标签。
- 如果打标器把角色物种、性别或身体类型识别错，不要擅自改成另一个身份；先按用户确认的主体身份保持稳定。
- 如果标签非常干净，`quality-check.csv` 记录“未修改”即可。

## 输出

`captions.jsonl` 每行对应一张图：

```json
{"file_name":"images/001.png","caption":"<触发词>，<类名>，三视图角色的单人训练底图，正面半身，冷静表情，简洁浅色背景，保持角色发型、服装和关键装饰一致。"}
```

`tags.csv` 字段：

```csv
file_name,trigger,class_name,view,shot,action,expression,background,style,quality_note
images/001.png,<触发词>,<类名>,正面,半身,自然站立,冷静,简洁浅色背景,<画风>,可用
```
