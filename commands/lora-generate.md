# /lora-generate

在用户明确同意后调用 `image_gen`。

## 步骤

1. 询问本次是单次还是批量。
2. 单次只出 1 张；批量必须继续询问本批出 `n` 张，不设置默认批量张数。
3. 调用前展示：
   - 本次模式与张数
   - prompt 编号
   - 完整提示词
   - 变量覆盖摘要
   - 三视图参考输入：`projects/<项目名>/refs/` 下记录的实际路径
   - 输出目录：`projects/<项目名>/images/`
4. 等待用户明确同意，例如“同意出图”“开始生成”“按这个清单生成”。
5. 调用 `image_gen`，并附带 `projects/<项目名>/refs/` 下记录的三视图作为图片输入参考。
6. 保存或复制返回图片到 `projects/<项目名>/images/`。
7. 更新 `prompts.md` 的输出文件和状态。

## 命名

- 首次生成：`001.png`、`002.png`
- 重生成：`001-r02.png`、`001-r03.png`

## 禁止

- 用户只说“继续优化”“看看”“可以吗”时，不视为同意出图。
- 不要只在文字提示词里提到三视图；必须把项目包内 `refs/` 的图片作为输入参考。
- 不要把图片只留在聊天附件或临时目录。
