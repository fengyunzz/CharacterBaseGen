# /lora-label

清洗最终训练集标签。

## 前置条件

- 计划图片已经全部生成。
- 用户确认全部满意。
- 外部打标器已经在 `projects/<项目名>/images/` 里为每张训练图生成同名 `.txt` 文件。

## 步骤

1. 确认用户要开始最终洗标签。
2. 读取 `projects/<项目名>/images/*.txt` 全部标签文件。除非用户明确指定单个文件，不要只洗其中一份。
3. 读取 `references/core-methodology.md`。
4. 需要统一动作或表情用词时，再读取动作和表情参考。
5. 使用最小变量原则：
   - 标签很干净时可以完全不改。
   - 需要改时，只改最小必要片段。
   - 说明改哪个 `.txt` 文件以及原因。
6. 若用户提前明确 trigger，把 trigger 加到每个 `.txt` 最前面。
7. 若没有明确 trigger，先完成其他清洗，最后再问是否添加 trigger。
8. 生成或更新：
   - `captions.jsonl`
   - `tags.csv`
   - `quality-check.csv`

## 禁止

- 不调用视觉工具。
- 不读取训练图片。
- 不读取 `prompts.md` 来推断画面。
- 不因为打标器误判就改变用户确认过的主体身份。
