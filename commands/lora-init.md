# /lora-init

初始化一个角色 LoRA 底图项目。

## 步骤

1. 确认或推断项目名。用户未给名称时，优先用参考图文件名；仍无法判断时用 `character-YYYYMMDD`。
2. 使用 `projects/<项目名>/` 作为唯一工作目录。
3. 记录参考图到 `refs/`，记录需求到 `brief.md`。
4. 从用户消息、文件名、三视图和上下文自动推断：
   - 角色名
   - 触发词
   - 类名
   - 画风
   - 必须保留
   - 禁忌元素
5. 只有关键信息无法判断且会影响出图时，才问最多一个简短问题。

## 禁止

- 不要要求用户填完整表格。
- 不要直接生成图片。
- 不要询问训练超参数，除非用户主动提到底模或训练器。
